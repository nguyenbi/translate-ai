# ライブ翻訳 / Dịch Trực Tiếp

[Tiếng Việt](README.md) | **日本語**

周りの音声やパソコンで再生中の音声を聞き取り、その場で翻訳して字幕表示する Web アプリ（PWA）です。
翻訳結果の読み上げにも対応しています。

## 主な機能

| 機能 | 内容 |
|---|---|
| 音声の入力元 | マイク（周りの音）／パソコンの音（システム音声の共有、PC のみ） |
| リアルタイム翻訳 | 話している途中から仮の翻訳を表示し、文が確定すると履歴に保存 |
| 対応言語 | 日本語・ベトナム語・英語・中国語・韓国語・タイ語（翻訳方向の入れ替え可） |
| 表示言語 | 日本語／ベトナム語を切り替え可能（初回は端末の言語に合わせて自動選択） |
| 読み上げ | 翻訳結果を音声で読み上げ（読み上げ中はマイクを一時停止） |
| 履歴 | ブラウザに最大 500 件保存、1 文ずつコピー可能 |
| レポート出力 | HTML（印刷・PDF 保存）、CSV（Excel）、TXT |
| インストール | スマートフォンのホーム画面に追加してアプリとして利用可能 |

## 使用技術

- **音声認識**：ブラウザ標準の Web Speech API（インターネット接続が必要）
- **翻訳**：Google 翻訳（無料エンドポイント）、失敗時は MyMemory に切り替え
- **フレームワーク**：なし（HTML / CSS / JavaScript のみ、ビルド不要）
- **ホスティング**：GitHub Pages

## フォルダ構成

```
.
├── index.html              # メイン画面
├── manifest.webmanifest    # PWA のインストール情報（名前・アイコン・色）
├── sw.js                   # Service Worker（アプリ全体を対象とするためルートに配置）
├── assets/
│   ├── css/style.css       # スタイル（ライト／ダークモード対応）
│   ├── icons/              # アプリアイコン（192px / 512px）
│   ├── img/logo.png        # ロゴの元画像（Git 管理対象外）
│   └── js/
│       ├── config.js       # 著作権者名（AUTHOR）、対応言語の一覧
│       ├── i18n.js         # 画面表示文言（ベトナム語／日本語）
│       ├── logo.js         # Base64 埋め込み済みのロゴ（自動生成）
│       ├── app.js          # 音声認識・翻訳・履歴・画面制御
│       └── report.js       # レポート出力（HTML / CSV / TXT）
└── scripts/make-logo.ps1   # logo.png を logo.js に埋め込むスクリプト
```

JavaScript は ES モジュールではなく通常のスクリプトとして `index.html` に記載の順で読み込みます。
そのため、`index.html` をローカルで直接開いても動作します。

## ローカルでの確認方法

1. リポジトリをクローンします。
2. Chrome で `index.html` を開きます。
3. マイクボタンを押し、マイクの使用を許可します。

## スマートフォンへのインストール

- **Android**：Chrome でリンクを開く → メニュー ⋮ →「ホーム画面に追加」または「アプリをインストール」
- **iPhone**：Safari でリンクを開く → 共有ボタン →「ホーム画面に追加」

## ロゴの差し替え

画像を `assets/img/logo.png` に配置し、次のコマンドを実行します。

```powershell
powershell -ExecutionPolicy Bypass -File scripts/make-logo.ps1
```

著作権者名は `assets/js/config.js` の `AUTHOR` で変更できます。

## 制限事項

- 音声認識・翻訳ともにインターネット接続が必要です。
- 一般の電話（通話音声）は OS の制限によりアプリから取得できません。
- アプリを画面に表示している間のみ聞き取ります（画面を消すと停止します）。
- 無料の翻訳サービスを使用しているため、翻訳の精度は保証されません。
- 「パソコンの音」を使う場合は、共有画面で「画面全体」を選び「システム音声も共有する」をオンにしてください。

## ブランチ運用（Git Flow）

| ブランチ | 役割 |
|---|---|
| `main` | 本番（GitHub Pages の公開元）。`release/*`・`hotfix/*` からのみマージ |
| `develop` | 開発の統合ブランチ。次回リリースに含める機能をまとめる |
| `feature/<名前>` | 機能ごとのブランチ。`develop` から作成し、完了後 `develop` にマージ |
| `release/<バージョン>` | リリース準備。`develop` から作成し、`main` と `develop` にマージしてタグ付け |
| `hotfix/<名前>` | 本番の緊急修正。`main` から作成し、`main` と `develop` にマージ |
